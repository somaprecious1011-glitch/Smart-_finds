SMART FINDS WEBSITE — BEGINNER GUIDE
===================================

FILES
- index.html: website content
- style.css: layout, colours and mobile-friendly styling
- script.js: automatically updates the copyright year

IMPORTANT
This is a starter website. It does not yet contain real products or affiliate links.
Add useful original content and only link to products you have researched. Disclose affiliate links clearly. Do not claim to be an Amazon Associate until Amazon accepts your application.

FREE PUBLISHING OPTION: GITHUB PAGES
You will need a GitHub account and an internet connection to publish. GitHub Pages can host a basic static website free on an eligible public repository. The resulting address is usually:
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
That address is only an example; your actual URL depends on the account and repository you create.

PUBLISHING STEPS (PHONE OR COMPUTER)
1. Open https://github.com/ and create/sign in to an account.
2. Create a new repository named smart-finds (a public repository is the simplest route for the free GitHub Pages workflow).
3. Open the repository and choose Add file > Upload files.
4. Upload index.html, style.css, and script.js. You may also upload this README.
5. Commit/save the uploaded files to the repository's main branch.
6. Open the repository's Settings.
7. Open Pages in the sidebar.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose branch "main" and folder "/ (root)", then save.
10. Wait a few minutes. Refresh the Pages settings screen; GitHub should show the published site link.
11. Open that link on your phone to confirm it works.

If the GitHub mobile website is difficult, use a browser menu option such as "Desktop site" if available. Do not share your password or verification codes with anyone.

BEFORE USING THE URL FOR AMAZON ASSOCIATES
- Amazon's application requirements can change. Check the current Amazon Associates operating agreement and application guidance for your marketplace.
- Amazon expects the site you submit to be yours or under your control, publicly accessible, and to contain meaningful original content. A blank or thin starter template may not qualify.
- Add useful, original product comparisons or guides before applying.
- Do not paste a made-up URL into the Amazon form.
- In the Amazon "Website(s)" box, submit the full published URL, including https://, only after the site is live.
- The "Mobile App or Alexa Skill URL(s)" box is for an app/Alexa skill you own or operate. If you do not have one, leave it blank if the form allows; do not put "WhatsApp" or a general app-store URL there.
- If you are under 18, follow Amazon's age and contract eligibility rules and involve a parent/guardian where required. Do not misstate your age or identity.

AFFILIATE DISCLOSURE
Keep a clear disclosure near affiliate links. For Amazon, check its current required wording and policies. Its commonly required statement is:
"As an Amazon Associate I earn from qualifying purchases."
Use it only if/when you are accepted into Amazon Associates, and follow the current programme terms.

CUSTOMISATION
